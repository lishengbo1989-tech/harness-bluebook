## 2. 正文全文

**结论先说:** 如果想让 DeepSeek Harness 落地到真实任务,这份《DSH 实战蓝皮书》是目前少数「中文、可复现、按任务组织」的资料,适合入门也适合当索引;它处于开发者预览阶段,是社区项目,别拿成熟商业产品的标准要求它。

下面按我实际翻下来的感受整理。

### 它解决了什么问题

DeepSeek Harness(`dsh`)是 DeepSeek AI 开源的 agent harness,能力不少:子代理、工作流编排、长期目标、Skills、沙箱权限、后台任务。但官方资料偏英文、偏架构,中文社区一直缺一份「从装到用」的向导。这份蓝皮书补的正是这个空档——静态文档站,19 个页面,以真实任务为主线组织,定位一句话:「从 0 到 1 先用起来,从 1 到 100 沉淀工作系统」。

### 值得看的部分

1. **7 章完整正文**:蓝皮书规划 4 篇 24 章,目前第 2/4/5/6/9/10/18 章已有完整正文——安装启动、配置模型、第一个任务、沙箱与权限、bash、文件读写、一切皆插件。前几章正好构成一条「装好 → 配置 → 跑第一个任务」的最短路径。
2. **6 个完整案例**:仓库审计、文件整理、子代理并行调研、长期目标、文档重写、每周巡检。都是社区真实场景,照着案例集页面可以复现,不是只讲思路。
3. **阅读指南按角色给路线**:新手入门、按真实任务选教程、团队落地,入口分开,不用从头到尾硬啃;另有「帮你解决」栏目,按场景描述问题找对应内容。

### 上手大概什么感觉

启动确实简单,一条命令:

```bash
npx @deepseek-ai/dsh web
```

Web UI 默认在 http://127.0.0.1:3080,配置模型后就能跑任务。我第一次跑通「文件整理」类任务,最大的感受是:文档里每一步都对应得上,不用靠猜。对我这种「先跑通再研究架构」的用法,第 6 章沙箱与权限、第 18 章一切皆插件(Cordis 架构)是后来回看最多的两章——前者是安全底线,后者决定了你扩展能力的思路。

### 什么样的人适合现在就看

我自己的判断是三类人最合适:一是刚听说 DeepSeek Harness、想找个中文入口的;二是已经在用别的 agent 工具、想对比一下「一切皆插件」这套架构的;三是想给团队搭 agent 工作流,需要一份按任务组织的落地资料做参考的。纯想看架构论文的反而没必要,它定位就是实践指南。

### 说两句实话

- 项目在**开发者预览阶段**,迭代快,文档和版本可能有出入;
- 这是**社区项目,与 DeepSeek 官方无隶属关系**,DeepSeek Harness 本体为 MIT 协议开源;
- 别指望「装完就生产力翻倍」——它更适合作为你搭建工作系统的起点,案例要自己复现、场景要自己沉淀。

### 怎么参与

看教程只是一半,另一半是共创:蓝皮书章节欢迎认领写作,你跑通的场景可以变成下一位读者的教程。
