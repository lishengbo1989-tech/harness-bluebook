PART 03 · CH. 18

一切皆插件:认识 Cordis 架构

Harness 的「一切皆插件」内核由 Cordis 驱动——理解它,你就理解了整个项目为什么这样组织。

#设计哲学

DeepSeek Harness 的核心架构是「一切皆插件」:工具、模型适配器、功能包都以插件的形式存在,按需装配。项目论文《A Programming Paradigm for Spatiotemporal Composability》从「时间与空间可组合」的角度阐释了这一设计——能力像积木,可以跨时间、跨空间自由组合,系统因此保持精简又高度可扩展。

#核心概念

  • 一切皆插件。没有铁板一块的巨石,能力都从插件获得。
  • Cordis 驱动。插件的生命周期、依赖与通信由 Cordis 统一管理。
  • 按需装配。用到什么加载什么,系统保持精简、可扩展。

#从官方文档开始

想深入内核,官方仓库是最好的起点。先读 docs/architecture.md 把握整体架构,再看 docs/development.md 了解开发流程;AGENTS.md 描述了 agent 协作约定;想动手做东西,docs/cookbook/ 里提供了 adding-a-tool、adding-a-package、adding-an-llm-adapter 等逐步教程;面向使用还有 docs/user/guide/(index、providers、python-sdk)与 apps/cli。

docs/architecture.md   # 整体架构
docs/development.md    # 开发流程
AGENTS.md              # agent 协作约定
docs/cookbook/         # adding-a-tool / adding-a-package / adding-an-llm-adapter
docs/user/guide/       # index / providers / python-sdk
apps/cli               # CLI 入口
以官方仓库为准
项目当前处于开发者预览阶段(MIT 协议),文档与接口都可能发生破坏性变更。阅读时留意版本,拿不准的内容以 GitHub 官方仓库为准。

#插件生态

社区插件仓库建议加上 dsh-plugin topic,便于按主题被发现;社区维护的 awesome-dsh-plugin 列表收录了大量现成插件,动手之前先看看有没有能直接用的。遇到问题可以在 GitHub Discussions 提问,也可以去 Discord 和社区交流。
