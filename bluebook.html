第一篇 使用手册:先把 Harness 用起来

CH. 01—08
  • CH. 01初识 DeepSeek Harness:能做什么,不能做什么定位、边界与「一切皆插件」的架构直觉。编写中
  • CH. 02下载、安装与启动安装 Node.js,运行 npx @deepseek-ai/dsh web,打开 http://127.0.0.1:3080。已发布
  • CH. 03Web UI 漫游:会话、工作区与设置认识主界面三块区域,理解「选择工作区」为什么是第一步。编写中
  • CH. 04配置模型提供方设置 → 模型:DeepSeek API 密钥、其他提供方与 OpenAI 兼容端点。已发布
  • CH. 05第一个任务:让 agent 跑通一次真实操作选一个能验收的小任务,理解工具调用、计划与审批的完整回路。已发布
  • CH. 06沙箱与权限:workspace-write 与 danger-full-access文件策略、命令审批与权限升级的边界意识。已发布

第二篇 案例篇:从一项任务到一支 AI 团队

CH. 09—17
  • CH. 09用 bash 执行命令与脚本环境探测、命令执行、输出解读与常见坑。已发布
