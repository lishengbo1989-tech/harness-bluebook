ECOSYSTEM CASE · FINANCE

生态案例:金融与股票

FINANCESTOCKSRESEARCH

查行情、读财报、跑组合风险分析,让数据与研究都在一个会话里,结论带来源。

#场景与目标

关注美股的个人投资者与金融研究者,需要快速拿到行情、历史数据、财报、分析师共识与新闻,同时做组合风险分析。难点在于信息分散且来源难以追溯,目标是让取数与研究流程化、结论可复核。

#用到的能力

  • 行情数据:dsh-us-stocks 基于 yahoo-finance2,提供美股行情、历史、财报、分析师共识与新闻。
  • 研究工作流:dsh-finance 提供金融研究工作流与组合风险工具。
  • 来源纪律:dsh-finance 重视市场事实来源纪律,输出可追溯。

#怎么做到的

dsh-us-stocks 把 yahoo-finance2 的数据能力封装成 DSH 工具,在对话里问行情、财报与共识即可直接取数;dsh-finance 把研究拆成固定工作流步骤,组合风险分析复用同一套流程,并守住「市场事实要有来源」的纪律,避免结论脱离依据。

#实际效果

数据查询与研究在一个会话里完成,行情、财报与新闻随手可得;组合风险分析有固定流程可重复执行,研究结论带来源、可复核,减少临时拼凑与无法追溯的判断。

#出处与上手

  • github.com/Realyujie/dsh-us-stocks — 美股行情与数据
  • github.com/zhang787jun/dsh-finance — 研究工作流与组合风险
dsh plugin --profile web add dsh-us-stocks
dsh plugin --profile web add dsh-finance
