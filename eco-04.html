ECOSYSTEM CASE · GIT

Git 工作树隔离交付:dsh-git-worktree

GITWORKTREEDELIVERY

变更放进独立工作树,AI 干活、人来验收,主线始终保持干净。

#场景与目标

让 agent 直接在主线工作区改代码,半成品容易混进主分支。dsh-git-worktree 把变更放进永久工作树(.dsh-worktrees),与主工作区完全隔离,适合「AI 产出、人来验收」的交付流程。该项目源自 Domi 的生产系统移植。

#用到的能力

  • Git 工作树:变更隔离在 .dsh-worktrees 永久工作树中,不动主线。
  • 生命周期:ready-for-review / apply / finish / discard 四阶段管理。
  • 收尾能力:冲突处理与安全清理,废弃工作树不会越积越多。

#怎么做到的

每次变更在独立工作树中完成,标记 ready-for-review 供人评审;apply 合入主线、finish 收尾、discard 弃用,全流程状态明确;冲突可处理,工作树可安全清理。

#实际效果

隔离交付让主线工作区始终保持干净;评审与合入节奏由人掌控,agent 的产出可以放心地接受或丢弃。

#出处与上手

仓库:github.com/wloops/dsh-git-worktree。安装与用法详见仓库 README。

安全提示
