生态案例:内容创作与视频

WRITINGVIDEOCREATION

网文写作、视频处理与 B 站素材分析,三个插件拼出一条创作流水线。

#场景与目标

网络小说作者与视频创作者要管理长篇连载的伏笔与语料,批量处理视频片段与字幕,还要从 B 站采集元数据、评论与弹幕做选题参考。目标是让这些重复劳动在 DSH 会话里直接完成。

#用到的能力

  • 写作引擎:dsh-tool-writing 支持并行起草、大纲头脑风暴与伏笔管理。
  • 检索与台账:语义向量检索语料库,用量台账记录产出,含机械校对与本地连载计划。
  • 视频工具:dsh-ffmpeg 提供 probe / cut / concat / encode / subtitle / extract / gif 七类工具,免 shell 传参。
  • 素材分析:dsh-bilibili 解析视频元数据、字幕、评论、弹幕与关键帧。

#怎么做到的

写作时先做大纲头脑风暴,再并行起草各章,伏笔与语料进入向量检索,连载进度由台账与本地计划跟进;ffmpeg 工具把常见视频操作封装成命令,在对话里描述意图即可;dsh-bilibili 一次性拉取视频的元数据与互动信息,供选题与剪辑参考。

#实际效果

写作流程被拆成可复用的步骤,伏笔不漏、语料随手可查,校对与连载计划在同一处维护;视频的剪切、拼接、转码与字幕处理不用再手写 shell 参数;B 站素材信息集中呈现,减少了手动抓取与整理。

#出处与上手

  • github.com/x2802490130-prog/dsh-tool-writing — 网文写作引擎
  • github.com/STARDUSTLC666/dsh-ffmpeg — 七类视频工具
  • github.com/CZX2244/dsh-bilibili — B 站视频分析
dsh plugin --profile web add dsh-tool-writing
dsh plugin --profile web add dsh-ffmpeg
dsh plugin --profile web add dsh-bilibili

具体加载方式与依赖以各仓库 README 为准。
