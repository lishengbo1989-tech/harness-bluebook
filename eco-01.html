ECOSYSTEM CASE · AGENTS

一支 AI 团队:dsh-agent-teams

AGENTSTEAMSWORKFLOW

把一个 DSH 会话变成「队长」,组装可持久化的子代理,用私信协调一支各司其职的 AI 团队。

#场景与目标

单会话里的 agent 各干各的,一旦任务互相依赖,就缺一个统一调度的大脑。dsh-agent-teams 把一个 DSH 会话变成「队长」:组装可持久化的子代理、把目标拆成依赖感知的任务、通过私信协调工作。给需要多代理协作、又不愿引入独立工作流引擎的团队。

#用到的能力

  • 子代理:团队成员是可续跑的 DSH 子代理,会话结束后仍可继续执行。
  • 任务模型:任务带显式状态,依赖未完成前不可认领,推进顺序有保证。
  • 私信通信:成员之间直接私信(邮箱式消息),由队长统一协调。
  • 插件机制:团队协议、九个协调工具、持久状态与实时 Web UI,无需独立工作流引擎。

#怎么做到的

一次 DSH 会话扮演「队长」:负责组装成员、拆解目标、认领与调度任务;依赖感知让任务按序推进;状态全部持久化,配合实时 Web UI 观察整支队伍的工作进度。

#实际效果

在 DSH 内部即可获得一支可持久、可观察、可续跑的 AI 团队:任务推进有显式状态与依赖约束,成员通过私信沟通,整条协作链路不依赖外部工作流引擎。

#出处与上手

仓库:github.com/NanmiCoder/dsh-agent-teams;npm 包:@nanmicoder/dsh-agent-teams。安装命令:

dsh plugin --profile web add @nanmicoder/dsh-agent-teams
