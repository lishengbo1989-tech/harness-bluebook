案例集 → 生态案例: 会话轨迹治理

ECOSYSTEM CASE · TRAJECTORY

会话轨迹治理:dsh-trajectory-governance

TRAJECTORYDEBUGGOVERNANCE

把扁平会话日志重建为多分支轨迹树,让长会话可回溯、异常可发现。

#场景与目标

长会话的日志是扁平的,一旦循环死锁或目标漂移,很难定位问题出在哪。dsh-trajectory-governance 把扁平会话日志重建为多分支轨迹树,检测循环死锁、无效重试与目标漂移,适合调试长会话和治理 agent 成本。

#用到的能力

  • 轨迹重建:扁平会话日志 → 多分支轨迹树。
  • 异常检测:循环死锁、无效重试、目标漂移自动标记。
  • 治理工具:成本归因告警、一键打断、断点 fork(走官方 API)。
  • 可视化:独立 GUI 标签页查看轨迹。

#怎么做到的

通过官方 API 读取会话数据,重建为树形轨迹;对死锁、无效重试与漂移打标记并按成本归因;失控会话可一键打断,也可在断点 fork 出新的分支继续调试。

#实际效果

长会话可回溯、异常可见、成本可归因;失控会话能一键打断,断点 fork 让调试不必从头再来。

#出处与上手

仓库:github.com/dfycaly98931680/dsh-trajectory-governance。安装与用法详见仓库 README。
