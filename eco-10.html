ECOSYSTEM CASE · DATABASE

数据库与数据工具:dsh-data-agent · dsh-toolkit

DATABASETOOLKITDATA

让 AI 连数据库写 SQL、跑确定性数据工具、构建可检索可审计的知识库。

#场景与目标

数据开发与分析里,「连库、写 SQL、跑小工具、翻资料」都是高频杂活。这一组插件的目标是把它们收进会话:dsh-data-agent 让 AI 连接数据库并编写 SQL,dsh-toolkit 提供确定性数据工具,dsh-kb-sieve 把散落文档变成可检索的知识库。

#用到的能力

  • 数据库连接:让 AI 连上数据库,按需求编写并执行 SQL。
  • 确定性工具:dsh-toolkit 提供时间、编码、json、计算器、csv、正则、markdown、diff、stat、schema 十个零依赖工具。
  • 可审计知识库:dsh-kb-sieve 用 SQLite FTS5 从 md/txt/docx/pdf 构建知识库包,检索可回溯。

#怎么做到的

三个插件分工明确:dsh-data-agent 负责「连库写 SQL」,把数据库连接与查询封装成会话内工具;dsh-toolkit 把高频数据杂活做成无依赖的确定性工具,输出稳定、结果可预期;dsh-kb-sieve 用 SQLite 全文检索(FTS5)索引本地文档,构建可审计的知识库包。

#实际效果

从「连库、写 SQL、跑工具、翻文档」到「一句话让 AI 代劳」;确定性工具输出可预期,知识库查询可审计、可回溯到源文档,适合对结果可靠性有要求的场景。

#出处与上手

社区仓库:github.com/omdsh-dev/dsh-data-agent · github.com/omdsh-dev/dsh-toolkit · github.com/omdsh-dev/dsh-kb-sieve

安装插件:

dsh plugin --profile web add dsh-data-agent
dsh plugin --profile web add dsh-toolkit
dsh plugin --profile web add dsh-kb-sieve

连接数据库需按仓库 README 配置连接信息;生产库请先确认权限边界。

安全提示
安装插件会在你的机器上以你的权限运行第三方代码,可能读取文件、使用凭证、访问网络。工具审批不会对插件代码做沙箱隔离;收录列表不等于安全审查,安装前请审阅源码,陌生插件请在无密钥的环境试用。
