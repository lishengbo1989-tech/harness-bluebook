生态案例:学术研究

ACADEMICREADINGLATEX

文献检索、模式化深读与 LaTeX 写作,三个社区插件把学术流程收进一个 DSH 会话。

#场景与目标

研究者与学生在读文献、整理笔记、撰写论文时常要在多个工具之间来回切换。目标是让 DSH 承担三类工作:学术助手 dsh-scholar 辅助检索与整理,五模式深读 dsh-deepread 把论文读出结构,再通过 dsh-overleaf 与 Overleaf 项目联动写作。

#用到的能力

  • 插件机制:三个项目都以 DSH 插件形式接入,在「一切皆插件」架构下装完即可用。
  • 模式化深读:dsh-deepread 提供快速、深度、知识地图、费曼、全书五种阅读模式。
  • 结构化输出:报告按 claim-evidence-data 组织,可导出 Mermaid/XMind 脑图与 Markdown/HTML。
  • 外部服务桥接:dsh-overleaf 通过 OverleafMCP 连接多个 Overleaf 项目。

#怎么做到的

dsh-scholar 作为学术助手常驻会话;dsh-deepread 把一篇论文按不同模式重读,产出带证据链的报告与脑图;dsh-overleaf 在会话内浏览、分析 Overleaf 项目,并通过 Git 更新,写作时不必切出浏览器。

#实际效果

文献阅读从「通读一遍」变成可复用的模式化流程:快速扫读、深度精读、费曼复述各得其所,知识地图方便复习与引用;论文写作与 Overleaf 联动,版本更新走 Git,全程留在对话里。

#出处与上手

  • github.com/lzszq/dsh-scholar — 学术助手
  • github.com/xiehuan123/dsh-deepread — 五模式深读
  • github.com/fly233338/dsh-overleaf — Overleaf 桥接
dsh plugin --profile web add dsh-scholar
dsh plugin --profile web add dsh-deepread
dsh plugin --profile web add dsh-overleaf

具体加载方式与依赖以各仓库 README 为准。

安全边界
安装插件会在你的机器上以你的权限运行第三方代码,可能读取文件、使用凭证、访问网络。工具审批不会对插件代码做沙箱隔离;收录列表不等于安全审查,安装前请审阅源码,陌生插件请在无密钥的环境试用。
