ECOSYSTEM CASE · EMAIL

邮件与日程:dsh-email · dsh-calendar

EMAILCALDAVAUTOMATION

把邮件与日程收进 DSH 会话:读信、搜信、发信、管文件夹与附件,日历事件交给 AI 打理。

#场景与目标

日常办公里,邮件与日程是信息进出的主通道,却和 AI 会话完全割裂。dsh-email 与 dsh-calendar 的目标是让自然语言驱动邮件与日历:列出、读取、搜索、发送邮件,以及查询和创建日程,减少在多个客户端之间来回切换。

#用到的能力

  • 插件机制:两个独立插件分别把邮件工具与日程工具注册进会话。
  • 协议支持:邮件走 IMAP/SMTP,日程走 CalDAV,覆盖主流服务商。
  • 审批闸门:发送邮件需审批确认,重要动作有人把关,降低误发风险。

#怎么做到的

dsh-email 按 IMAP/SMTP 封装出邮件操作:列出、读取、搜索、发送、文件夹与附件管理,内置 QQ、163、126、Sina、Aliyun、Gmail、Outlook、iCloud 等服务商预设并支持多账号。dsh-calendar 对接 Google、iCloud、Nextcloud 或自定义 CalDAV 端点,自动展开 RRULE 重复规则,让「每周例会」这类事件按规则呈现。

#实际效果

收信检索、发信、日程查询与创建都能在会话里用对话完成;多账号与主流服务商开箱即用,重复事件按规则展开;发送动作走审批闸门,结果可留痕、可回溯。

#出处与上手

社区仓库:github.com/STARDUSTLC666/dsh-email 与 github.com/STARDUSTLC666/dsh-calendar

安装插件:

dsh plugin --profile web add dsh-email
dsh plugin --profile web add dsh-calendar

首次使用需按仓库 README 配置账号(通常用应用专用密码)。

安全提示
安装插件会在你的机器上以你的权限运行第三方代码,可能读取文件、使用凭证、访问网络。工具审批不会对插件代码做沙箱隔离;收录列表不等于安全审查,安装前请审阅源码,陌生插件请在无密钥的环境试用。
