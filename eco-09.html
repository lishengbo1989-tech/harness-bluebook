ECOSYSTEM CASE · BROWSER

浏览器与电脑操作:dsh-browser-control · dsh-computer-use

BROWSERCOMPUTER-USEAUTOMATION

让 AI 替你「看得见」地操作浏览器和电脑:开网页、点按钮、填表单,或直接驱动 macOS 界面。

#场景与目标

网页自动化与本地桌面任务,通常要专门写脚本。这一组插件的目标是让 AI 直接从会话驱动真实浏览器与电脑:打开网页、点击、填表,或操作 macOS 界面,把重复操作交给对话完成。

#用到的能力

  • Playwright MCP:dsh-browser-control 驱动真实可见的 Chrome,提供约 80 个 browser_* 工具与实时截图面板。
  • 文本优先控制:dsh-computer-use 用后台 Chromium 加无障碍优先的 macOS 控制,不抢鼠标指针。
  • 零依赖 CDP:dsh-pilot 直接走 CDP 协议控制浏览器,提供 8 个 pilot_* 工具。

#怎么做到的

三个插件是三种取舍:dsh-browser-control 走 Playwright MCP,浏览器真实可见、工具面最全,适合需要盯过程的场景;dsh-computer-use 面向「不打断你干活」的自动化,后台跑 Chromium、macOS 控制走无障碍接口,操作不抢鼠标指针;dsh-pilot 零依赖、体积小,直接用 CDP 协议控制浏览器。

#实际效果

网页与桌面操作都能从会话发起,实时截图面板让过程可见、可控;按场景选插件:重交互用 browser-control,后台批处理用 computer-use,轻量控制用 pilot。

#出处与上手

社区仓库:github.com/kyo615/dsh-browser-control · github.com/ZRui-C/dsh-computer-use · github.com/guo6x/dsh-pilot

安装插件:

dsh plugin --profile web add dsh-browser-control
dsh plugin --profile web add dsh-computer-use

dsh-pilot 同样可用 dsh plugin --profile web add dsh-pilot 安装;各仓库 README 有详细的工具清单与用法。

安全提示
安装插件会在你的机器上以你的权限运行第三方代码,可能读取文件、使用凭证、访问网络。工具审批不会对插件代码做沙箱隔离;收录列表不等于安全审查,安装前请审阅源码,陌生插件请在无密钥的环境试用。
